# NOTJUST — Official Press Kit

Self-contained English electronic press kit for NOTJUST, formerly known as LXBE.

## Open locally
Open `index.html` in a modern browser.

## Publish
Upload this project to a static host such as Netlify, Cloudflare Pages, GitHub Pages, or any standard web server.

All logos and photography used by the page are stored inside `assets/`. The project does not depend on the former Manus website.

The 2026 performance list includes Chica Club — Barcelona, Spain, placed after Cantina 15.

## Browser icon
The NOTJUST wordmark is used throughout the site. The legacy LXBE name is retained only as a reference to the artist's previous identity.

## Interactive map
The International section includes a self-contained SVG world map. Countries where NOTJUST has performed are highlighted in red and link to the matching performance year.
